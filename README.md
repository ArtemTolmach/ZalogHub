# Tidy — список задач

Простой список задач на React и TypeScript. Данные сохраняются в `localStorage` и остаются после перезагрузки страницы.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Для production-сборки используйте `npm run build`, для локального просмотра сборки — `npm run preview`.

## Возможности

- добавление задач; пустые строки и пробелы не принимаются;
- отметка о выполнении и удаление задач;
- фильтры «Все», «Активные» и «Выполненные»;
- сохранение задач в браузере;
- адаптивный интерфейс и индикатор прогресса.

## Время выполнения

Примерная оценка: 45 минут.
