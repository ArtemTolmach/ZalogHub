# Tidy - список задач

Лёгкое приложение для повседневных дел: добавляйте задачи, отмечайте выполненные и держите список под рукой на компьютере или телефоне.

## Возможности

- Добавление задач с названием и кратким описанием.
- Фильтры **Все**, **Активные** и **Выполненные** с количеством задач.
- Отметка о выполнении и удаление отдельных задач.
- Очистка списка от всех выполненных задач.
- Переключение языка интерфейса между **русским** и **английским**.
- Автоматический выбор языка по настройкам браузера и сохранение выбранного языка.
- Сохранение задач в браузере: список остаётся после перезагрузки страницы.
- Адаптивный интерфейс для мобильных устройств и больших экранов.

## Технологии

**React · TypeScript · Vite · Sass · SCSS Modules**

## Запуск проекта

Требуется Node.js **20.19+** или **22.12+**.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале.

```bash
npm run build    # production-сборка
npm run preview  # локальный просмотр production-сборки
```

## Структура проекта

```text
src/
├── components/
│   ├── TaskComposer.tsx   # форма добавления задачи
│   ├── TaskFilters.tsx    # фильтры и счётчики
│   └── TaskList.tsx       # список и карточки задач
├── constants/
│   └── tasks.ts           # фильтры и ключ хранения
├── hooks/
│   └── useTasks.ts        # состояние и операции над задачами
├── types/
│   └── task.ts            # типы Task и TaskFilter
├── utils/
│   └── taskStorage.ts     # чтение и сохранение задач
├── i18n.tsx               # переводы и переключение языка
├── App.tsx                # сборка основного интерфейса
└── main.tsx               # точка входа React
```
